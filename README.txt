CartyFinds_ Website - fixed starter ZIP

IMPORTANT: Keep the folder structure exactly as supplied. Upload ALL files, not only index.html.

Files:
- index.html
- style.css
- script.js
- images/ (8 SVG product illustrations)

Preview:
1. Extract this ZIP.
2. Open index.html in a modern browser. If your phone's file viewer shows a blank page, publish it using GitHub Pages or use a local web server instead.

GitHub Pages:
1. Create/open your public repository.
2. Upload index.html, style.css, script.js, README.txt, and the complete images folder to the repository root.
3. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the published URL after deployment finishes.

WhatsApp checkout:
Open script.js and set WHATSAPP_NUMBER to your number with country code, digits only, e.g. 919876543210. Do not use this example number as your own.

This is a frontend starter, not a complete production payment/order backend. Prices and ratings are demo content.
